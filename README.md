# SNVX — Atelier Synapse (SVT Cycle 4)

Page web interactive (HTML/CSS/JS autonome) pour l'atelier « Le messager invisible ».

## Mise en ligne via GitHub Pages

Le code est déjà poussé sur la branche `main` du dépôt `Bamiel2025/SNVX`.

Pour activer GitHub Pages :

1. Aller sur https://github.com/Bamiel2025/SNVX/settings/pages
2. **Source** : `Deploy from a branch`
3. **Branch** : `main` / `/ (root)` → **Save**
4. Attendre ~1 minute, l'URL sera :
   `https://bamiel2025.github.io/SNVX/`

## Lancement local (optionnel)

Ouvrir simplement `index.html` dans un navigateur moderne (Chrome / Edge / Firefox récents).
Aucune dépendance à installer — Three.js et les polices sont chargés via CDN.
